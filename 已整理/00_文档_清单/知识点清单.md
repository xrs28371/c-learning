# C 语言知识点清单（指针 / 字符串 / 二维数组）

> 来源：ni-ha 学习记录整理。适合复习，先看"一句话"，再看细节。

---

## 一、数组基础

- 数组是**连续**的一排变量，同类型。
- 求元素个数：`len = sizeof(arr) / sizeof(arr[0])`
- 数组名 `arr` 作为表达式 = 首元素的地址（但 `sizeof(arr)` 是整个数组的字节数！）

## 二、指针基础（最重要）

- **指针 = 存地址的变量**。`p` 是指针（8 字节），`*p` 是解引用（取出指向的值）。
  - `p` 的类型：`int*` / `char*`；`*p` 的类型：`int` / `char`
  - 口诀：**p 是写着地址的纸条，*p 是顺着纸条找到的房子**
- **步长**：`指针 + 1` 跳过"它指向的那个东西"的大小
  - `char* +1` 跳 1 字节；`int* +1` 跳 4 字节；`int(*)[3] +1` 跳 12 字节
- **三个地址别搞混**：
  - `arr`      → `int*`（首元素地址）
  - `&arr[0]`  → `int*`（同上）
  - `&arr`     → `int(*)[10]`（整个数组的地址，`+1` 跳 40 字节）
- **传地址才能改原值**：函数形参写指针，调用传 `&x` 或数组名。
- **指针大小**：64 位程序 = 8 字节，32 位 = 4 字节（int 始终 4 字节）。
- **野指针三种成因**：
  1. 未初始化（用 `NULL` 或立即赋值）
  2. 越界访问
  3. 指向已释放的局部变量（函数返回局部变量地址）
- **const 指针**：`const int* p` 不能通过 `*p` 改值，但 `p` 可以换指向。

## 三、字符串

- 字符串 = `char` 数组 + **`'\0'` 结尾**（printf %s 靠它知道在哪停）。
- `char* s = "hello"`（字面量，只读区，不能改）；`char s[] = "hello"`（可修改）。
- 遍历模板：`while (*p != '\0') { ... p++; }`
- `size_t` = 无符号整数，打印用 **`%zu`**。
- 形参 `const char*` = 只读承诺，防止误改。
- **拼接 strcat 三步**：找 dest 末尾 → 抄 src → 补 `'\0'`。
- **缓冲区溢出**：dest 空间不够就写越界，未定义行为（可能崩、可能不崩，但一定错）。

## 四、二维数组（内存是摊平的一排）

- `int arr[2][3]`：逻辑是 2 行 3 列，内存是连续 6 个 int。
- **地址公式**：`&arr[i][j] = 基地址 + (i × 列数 + j) × sizeof(int)`
- **行指针** `int (*p)[3]`：p 指向"一整行"，`p+1` 跳一行（3×4=12 字节）。
- **传参必须写死列数**：`void f(int (*p)[3], int rows)`，编译器靠列数算地址。
- 访问元素：`p[i][j]` 等价 `*(*(p+i)+j)`。
- 求行数/列数：
  - 行数 = `sizeof(arr) / sizeof(arr[0])`
  - 列数 = `sizeof(arr[0]) / sizeof(arr[0][0])`
- **一级指针平铺**：`int* q = &arr[0][0];` 然后 `q[i*列数+j]`。
- 循环里"每行清零"：`int sum = 0;` 写在外层循环**里面**（块作用域，每轮重建）。

## 五、指针数组 vs 数组指针（易混）

| | 指针数组 | 数组指针 |
|---|---|---|
| 写法 | `int* p[3]` | `int (*p)[3]` |
| 本质 | **数组**（装 3 个指针） | **指针**（指向含 3 个 int 的数组） |
| sizeof | 3 × 8 = 24 | 8（就一个指针） |
| 读法 | 变量名右边有 `[]` → 数组 | 被括号包住先跟 `*` → 指针 |

- 常见用途：指针数组存多个字符串；数组指针用于二维数组传参。
- `char* names[3]` 的元素 `names[1]` 是 `char*`（指针）。

## 六、其它要点

- **变量作用域/生命周期**：`{}` 块内声明的变量，执行到右括号就销毁；要"每轮重建"就声明在循环体里。
- **printf 格式**：`%d` int、`%p` 地址（要 `(void*)` 强转）、`%s` 字符串、`%zu` size_t、`%c` 字符。
- **assert 断言**：debug 下生效，条件为假就终止并定位。
- **未定义行为**：越界读/写不一定立刻崩，但结果不可靠——不要赌运气。

## 易错点自查（快速过一遍）

1. `p` 和 `*p` 谁是地址？谁是值？→ p 是地址，*p 是值
2. `int* a[5]` 的 sizeof？→ 40（64位，5×8）
3. `int (*p)[4]` 的 `p+1` 跳几字节？→ 16
4. 二维数组传参为什么必须写列数？→ 编译器要算 (i×列数+j) 的地址
5. strcat 最后为什么必须补 `'\0'`？→ 否则 printf 不知道在哪停
